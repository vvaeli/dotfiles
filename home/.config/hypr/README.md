# Hyprland · MD3

Палитра: фон #141218, текст #e6e0e9, акцент #d0bcff, успех #a8dab5.
Панель и рамка 6 px — Quickshell; зазор от рамки до плиточных окон 8 px.
Активное окно выделено сиреневой обводкой 1 px, у остальных обводка прозрачная.
Тени включены с плавным усилением у активного окна, скругление 18 px. Существующие мониторы и раскладка сохранены.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| Super+F | Развернуть всё окно на монитор, сохранив панели приложения; повторное нажатие возвращает размер |
| Super+L | Блокировка |
| Super+R | Hyprlauncher |
| Super+B | Панель и рамка |
| Print | Выделение области или клик по окну → Satty |
| Shift+Print | Текущий монитор → файл и буфер без редактора |
| Ctrl+Print | Выделение области → файл и буфер без редактора |
| Super+Print | Активное окно → Satty |
| Super+Shift+Print | Интерактивный выбор окна → Satty |

Скрипт `scripts/screenshot` поддерживает area/window/active/screen и
`--no-edit`/`copy-only`. Область и окно выбираются через slurp, снимок делается
после выбора через grim. Старый замороженный выбор Quickshell заменён этим
пайплайном. Satty открывается на весь экран с кистью; Enter и Esc сохраняют
результат, копируют PNG и закрывают редактор. Автосохранение сохраняет рисунок
при обычном закрытии окна. Файлы: ~/Pictures/Screenshots/YYYY-MM-DD_HH-MM-SS.png.
Зависимости: `sudo pacman -S grim slurp satty jq wl-clipboard libnotify`.
Подробности: `scripts/SCREENSHOTS.md`; традиционные binds: `screenshot-bindings.conf`.

## Компоненты

- `hyprtoolkit.conf`: общая палитра, Adwaita Sans, скругления 24/12 px;
  используется hyprlauncher, hyprpolkitagent и GUI-утилитами Hyprland.
- `hyprlauncher.conf`: окно 560×380, приложения, `=` калькулятор, `.` Unicode.
- `hyprlock.conf`: единый экран блокировки с часами и датой; без обводки поля пароля.
  Кнопка панели и Super+L используют `scripts/lock`, защищённый от повторного запуска.
- `hypridle.conf`: блокировка после 10 минут, отключение экранов после 11 минут.
  Перед сном блокирует сеанс, после пробуждения включает экраны. Автосон не настроен.
- `hyprpaper.conf`: обычные графические обои `/usr/share/hypr/wall0.png` на всех экранах.
  Свои обои можно указать в `path`, рабочий стол не заливается цветом оболочки.
- `scripts/session-start`: запуск daemon-компонентов без дублей при загрузке конфига,
  передача окружения Wayland службам D-Bus и порталам.
- GTK и Ghostty используют тёмный фон и шрифт темы; Satty запускается в Adwaita Dark.

Логи запуска — `~/.local/state/hypr/`. Оригинальные конфиги сохранены рядом с суффиксом `.bak-...`.
Синтаксис компонентов сверялся с документацией установленных версий и
[Hyprtoolkit](https://wiki.hypr.land/hypr-ecosystem/user/hyprtoolkit/),
[Hyprlauncher](https://wiki.hypr.land/Hypr-Ecosystem/hyprlauncher/),
[Hypridle](https://wiki.hypr.land/Hypr-Ecosystem/hypridle/),
[Hyprpaper](https://wiki.hypr.land/Hypr-Ecosystem/hyprpaper/).

Применение: `hyprctl reload`. Скрипт автозапуска запускает недостающие компоненты;
уже открытые приложения получают новое оформление после перезапуска.

Тени окон: радиус 24 px, активная тень rgba(00000088), неактивная
rgba(00000030), смещение вниз 4 px. Переключение фокуса плавно меняет
силу тени за 300 мс через fadeShadow.

Мультимедийные клавиши используют scripts/system-control. OSD громкости,
выключения звука, микрофона и яркости показывает фактическое значение на
мониторе с фокусом, не перехватывает ввод и исчезает через 1,6 с после
последнего нажатия. Для яркости требуется brightnessctl и аппаратная подсветка.
